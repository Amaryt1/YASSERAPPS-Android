# Studio V0.9.1
One replacement action. For authorized, integrated hosts only: package the native-brand-v1 profile, BrandRuntime, BrandDialog and supporting classes, and call BrandRuntime.showOnLaunch(activity) instead of the host's optional promo. The tool checks the declared contract, renderer classes and a call site before exporting, applies the saved preset, preserves protected keys and verifies the resulting profile and runtime after signing. The Studio itself is an integrated test host: select the original Studio V0.9.1 APK, change the preset, replace, export, install and launch to see the embedded dialog. Existing V7 update path remains separate. Arbitrary third-party APKs, including old LITEAPKS wrappers without this integration, are not supported for replacement; no deletion fallback. Runtime device testing pending.
