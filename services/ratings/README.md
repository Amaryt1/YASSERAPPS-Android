# YASSERAPPS shared ratings
Deploy on an owner-controlled server with Python 3.11+, persistent storage and an HTTPS reverse proxy. `pip install -r requirements.txt`; set `RATINGS_SECRET` to a random secret of 32+ characters and `RATINGS_DB` to a persistent database path. Run `uvicorn main:app --host 127.0.0.1 --port 8080`. Configure the proxy's trusted client-IP handling; limit request body size and add per-IP rate limits. Check `/health`, then set `catalog/ratings-service.json` enabled=true and baseUrl to the actual HTTPS origin. Android clients use a random per-install UUID; one rating per install/app, replaceable, no comments. Not identity-verified; further abuse controls may be needed. Never publish secrets to GitHub. No server is deployed by this commit.
