# YASSERAPPS V9 — الإدارة والنشر

## إضافة وإدارة التطبيقات
افتح [لوحة الإدارة](../admin/index.html)، واملأ بيانات البرنامج، ثم انسخ JSON الذي تولده اللوحة.
للإضافة أو التحديث: GitHub → Actions → Manage YASSERAPPS catalog → Run workflow؛ اختر upsert والصق JSON في entry_json.
للإخفاء: اختر disable والصق JSON مثل {"id":"newpipe.official"}. للإظهار مجددًا اختر enable.
هذه الإدارة تتطلب حساب GitHub عنده صلاحية كتابة على مستودعك، ولا تحتاج توكن داخل تطبيقات المستخدمين.
إذا تريد رابطًا ويب للوحة، فعّل GitHub Pages من Settings → Pages → Source: GitHub Actions، ثم شغّل Actions → Publish YASSERAPPS admin web panel. لوحة HTML المعروضة عامة للقراءة، لكن النشر الفعلي يتطلب حساب GitHub مخوّل؛ لذلك لا تحتوي اللوحة أي كلمة مرور أو توكن.
التعديل على [catalog/apps.json](../catalog/apps.json) يحدث دون إعادة بناء APK.

## التطبيقات التجريبية المرخصة
- NewPipe 0.29.3، الترخيص GPL-3.0، رابط الإصدار الرسمي مع بصمة SHA-256.
- Shattered Pixel Dungeon 4.0.2، الترخيص GPL-3.0، رابط الإصدار الرسمي مع بصمة SHA-256.
هذه الملفات من مطوريها الأصليين، ولا تعني أن جميع روابط التطبيقات الأخرى آمنة أو مصرح بها للنشر.

## توقيع متجر YASSERAPPS الدائم
أنشئ مفتاح JKS على Mac أو كمبيوتر خاص بك:

    keytool -genkeypair -v -keystore yasserapps-release.jks -alias yasserapps -keyalg RSA -keysize 3072 -validity 10000

احتفظ بالمفتاح وكلمات المرور بنسختين آمنتين **خارج المستودع**. ضياعه قد يمنع تحديث التطبيقات التي وقعتها به.

افتح GitHub Repository → Settings → Secrets and variables → Actions، ثم أضف أربعة Repository Secrets:
- YASSERAPPS_KEYSTORE_B64: محتوى ملف JKS مشفرًا بصيغة Base64 (على macOS: base64 -i yasserapps-release.jks).
- YASSERAPPS_STORE_PASSWORD: كلمة مرور المخزن.
- YASSERAPPS_KEY_ALIAS: الاسم المستعار، غالبًا yasserapps.
- YASSERAPPS_KEY_PASSWORD: كلمة مرور المفتاح.

**لا تشارك المفتاح أو كلمات المرور بالدردشة، ولا ترفع ملف JKS إلى GitHub.**
بعد تهيئة الأسرار، افتح Actions → Publish signed YASSERAPPS APK → Run workflow. يبني Release، يوقعه بنفس المفتاح، يتحقق من الشهادة، ينشر APK على GitHub Releases، ويحدث [catalog/store-release.json](../catalog/store-release.json) برابط الإصدار وبصمته.
ملف التحديث ما زال **معطّلًا عمدًا** حتى إصدار Release رسمي موقّع. لا تنشر النسخ التجريبية عليه.

## تحميل وتثبيت الملفات
- APK مباشر: يعرض التقدم ويحفظ السجل، ويتحقق من البصمة إن توفرت، واسم الحزمة ورقم الإصدار قبل تثبيت بموافقة Android.
- APKS وAPKM وXAPK المحتوية APK splits فقط: تمر عبر PackageInstaller.Session. هذا لا يضمن نجاح كل حزمة من مصدر غير معروف.
- XAPK يحتوي OBB أو Android/data: **مرفوض من المثبت الآلي**؛ أندرويد 11 والأحدث يحدّان وصول التطبيقات إلى مجلدات بيانات/OBB الخاصة بتطبيقات أخرى. لا نقدّم تثبيتًا ناقصًا على أنه ناجح.
- التحميلات الكبيرة تعتمد على مساحة الهاتف واستجابة الخادم؛ سيظهر الفشل وسبب الخطأ قدر الإمكان.

## تحديثات التطبيقات والمتجر
قسم تحديثات التطبيقات يقارن versionCode مع البرامج المثبتة التي يسمح النظام برؤيتها. قد تخفي قيود Android برامج لا تملك واجهة إطلاق. ولا يمكن تثبيت تحديث إذا تغيّرت هوية التوقيع.
فحص تحديث المتجر يدوي عند الفتح والإعدادات، مع مهمة دورية وإشعارات عند منح صلاحية الإشعارات. كل تحديث يحتاج موافقة المستخدم؛ لا تثبيت صامت.

## الاختبارات قبل النشر
1. اختبر الرئيسية والبحث والتنزيلات والإعدادات والتحديثات على أجهزة فعلية مختلفة.
2. جرّب تنزيل NewPipe واللعبة من روابط مطوريها وتحقيق SHA-256.
3. جرّب الإلغاء، إعادة المحاولة، انقطاع الشبكة وWi-Fi فقط.
4. اختبر تركيب ملف APK وAPKS/APKM/XAPK مرخص معروف، ولا تعتبر OBB مدعومًا.
5. جرّب توقيع APK رسمي بمفتاحك وتحديث نسخة رسمية سابقة بنفس المفتاح.
6. تأكد من حقوق نشر أي APK تضيفه إلى كتالوجك.

**نطاق العمل:** مستودع Amaryt1/YASSERAPPS-Android فقط؛ حافظنا على هوية YASSERAPPS السوداء والخضراء.
