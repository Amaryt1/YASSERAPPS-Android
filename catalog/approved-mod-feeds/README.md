# MOD-only catalogue
Only owner-reviewed modified releases with a public permission reference and evidence of modifications are accepted. Place authorized exports in this directory. Each JSON file contains source, permissionUrl, reviewedByOwner=true and apps. Each app requires id, name, packageName, category, version, versionCode, modified=true, modDescription, modEvidenceUrl, publisherUrl and optionally iconUrl/license. Evidence and permission must be reviewed by the owner; a boolean alone does not establish authenticity. No ordinary listings or unverified direct downloads are accepted. Empty catalogue is valid.
